## 列表
是由一系列按特定顺序排列的元素组成

- 在 Python当中，列表都是用 [] 来表示，用逗号分隔其中的元素
- [] 列表是从0开始进行顺取索引的
- python 为访问最后一个元素提供了一个特殊语法，通过 将 索引 指定为 - 1，可以返回列表的最后一个元素。

### 列表的操作

- 添加元素到末尾 append（）
- - 可以先创建空列表，再使用这个函数往里面添加值。
- 在列表指定位置添加元素， insert（）
- - 添加了元素之后，其余元素往后移
- 删除列表当中的元素 del 根据列表位置删除元素
- - 这个方法是删除了值无法再使用
- 删除列表当中，删除的值可以使用的方法 pop（）
- - 相当于这个返回了一个值，要用一个变量去接住，或者直接打印也可以。
- 按照值来删除列表 remove（）
- - 这个函数没有返回值

#### 列表的排序

- sort（）能让你快速的对列表进行排序
- - 这个函数改变的是列表本身，并且无法恢复到原来的顺序。
- - 排序是通过首字母 ASCII 的大小进行的
- reverse（）用来反转列表的排列顺序
- - 并不是字么顺序相反排列元素，只是反转列表元素顺序


## FOR循环

使用for循环，可以让Python去处理每一个元素，从而避免这些问题

- 在编写for循环时，可以给将一次与列表中的每个相关联的临时变量指定任意的名称
- - 起的临时变量，应该要有一些含义，和列表要相关（提高可读性）
- 位于 for 语句后面的且属于循环组成部分的代码，一定要进行缩进
