# Python文件

- python 这个语言很简单，其余很多可以根据c来借鉴学习

现在学了几个函数，应该是属于标准库里面的

- strip（） 用来去掉字符串里面的全部空格 如果没有说明的话，分左右
- upper（） 讲这个字符串大写
- lower（） 将字符串小写
- title（） 将每个单词的首个字母大写

## 数

 python中可以直接对数进行运算
 - “+”
 - “-”
 - “*”
 - “/”
 - "**"

将任意两个数相除，结果总是浮点数，即便这两个数都是整数且能整除

- 常量是在程序的整个生命周期内都保持不变的变量
- - python没有内置的常量类型，但Python程序员回志永全大写字母来指出某个变量作为常量，其值始终不变
