## 列表
是由一系列按特定顺序排列的元素组成

- 在 Python当中，列表都是用 [] 来表示，用逗号分隔其中的元素
- [] 列表是从0开始进行顺取索引的
- python 为访问最后一个元素提供了一个特殊语法，通过 将 索引 指定为 - 1，可以返回列表的最后一个元素。

### 列表的操作

- 添加元素到末尾 append（）
- - 可以先创建空列表，再使用这个函数往里面添加值。
- 在列表指定位置添加元素， insert（）
- - 添加了元素之后，其余元素往后移
- 删除列表当中的元素 del 根据列表位置删除元素
- - 这个方法是删除了值无法再使用
- 删除列表当中，删除的值可以使用的方法 pop（）
- - 相当于这个返回了一个值，要用一个变量去接住，或者直接打印也可以。
- 按照值来删除列表 remove（）
- - 这个函数没有返回值

#### 列表的排序

- sort（）能让你快速的对列表进行排序
- - 这个函数改变的是列表本身，并且无法恢复到原来的顺序。
- - 排序是通过首字母 ASCII 的大小进行的
- reverse（）用来反转列表的排列顺序
- - 并不是字么顺序相反排列元素，只是反转列表元素顺序


## FOR循环

使用for循环，可以让Python去处理每一个元素，从而避免这些问题

- 在编写for循环时，可以给将一次与列表中的每个相关联的临时变量指定任意的名称
- - 起的临时变量，应该要有一些含义，和列表要相关（提高可读性）
- 位于 for 语句后面的且属于循环组成部分的代码，一定要进行缩进

- 在 for 循环中 有许多方法能够高效的操作数值里表
- - range（）函数，区间是左闭右开
- - range（）本质是一个 range类型
- - range（）还可以指定步长，即添加第三个参数

列表推导式：

- 列表推导式将for循环和创建新元素的代码合并，自动追加新元素
- 将for循环每次拿出来的元素，添加进列表


列表切片：
 
在Python中，鹅考处理列表的部分元素，称为切片。

要创建切片，可指定第一个和最后一个元素的索引,python到达第二索引前元素停止，中间用 ：
切出来还是列表

- 在原来的列表索引中，始终是一个单独的数字，那就是0维的，是一个数(发生了降维)
- 在后来的列表切片中，取出来的是一个向量，那就说明这个是1维的，是一个向量
- 切片当中也可以指定相应的步长


复制列表：

要复制列表，可创建包含整个列表的切片，同时省略起始和终止索引（[:]）

这让Python创建一个起始第一个元素，终止于最后一个元素的切片，即复制整个列表

元组：

Python将不能修改的值称为不可变的，不可变的列表称为元组（tuple）

元组看起来很像列表，但是使用圆括号而不是方括号，定义元组后，可以已使用索引来访问其元素


遍历元组中所有的值

- 元组的遍历和列表的遍历差不多 使用 for

修改元组的变量

- 修改的不是元组当中的一个值，而是整个元组的变量
